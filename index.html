FAQ

Everything you need to know

How to install a config

1

Download the .txt config file from Discord.

2

Copy the downloaded file.

3

Navigate to your macro's "Settings" folder.

4

Paste it into the matching subfolder (raids / story / tourney / expeditions), or the main Settings folder for custom configs.

5

Open the macro and select your config.

Every mission must be started from the lobby.
